# Advanced lab authoring guide

Advanced labs live in `src/modules/<slug>` and are routed through `/labs/[slug]`.
Each lab must expose the same learning contract: a common question, guided first
interaction, exploration mode, an accessible change summary, verified source links,
a reflection prompt, deterministic non-sensitive share state, and a complete
non-canvas equivalent. Reduced motion changes presentation, never learning content.

The registry is the source of truth for the Labs index, sitemap, and navigation.
Every factual claim belongs in a source packet with a stable URL and locator. New
labs must include unit, keyboard, reduced-motion, mobile, and visual coverage before
they are added to the registry.

Historical module runtimes removed in the flagship repair remain available through
Git history and are discussed in `/built`; do not copy their private data APIs or
static-poster reduced-motion pattern into new work.
