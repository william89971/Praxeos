# Two-dimensional sketch rules

The active Labs do not use this directory. Their precise interaction graphics are SVG and HTML under `src/labs`.

The remaining ambient sketch is optional atmosphere. It must be deterministic from a seed, bounded in work, paused off-screen, and paired with a complete textual description. Reduced-motion users receive a stable final state. The sketch may never carry required instructions, evidence, or learning actions.

Do not add WebGL, Three.js, or a static-poster substitute for an interactive learning task. If a future concept requires an interaction, build the accessible 2D state model first and render it second.
